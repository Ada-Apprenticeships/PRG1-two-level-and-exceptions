# PRG1: Two-level data, and handling errors (PRIM activities)

Day 8. Seven activities plus two stretch folders, each in its own folder, each
with the code and its tasks together in one place.

## PRIM

| Step | What you do |
|---|---|
| **Predict** | Say what the code will do **before** you run it. Write it down. |
| **Run** | Run it. Compare against your prediction. |
| **Investigate** | Work out *why* it behaves that way. |
| **Modify** | Change something specific, predicting the effect before each change. |

## The activities

### Morning: data with two levels

| Folder | Focus |
|---|---|
| `activity-1-rows-and-columns/` | A grid of numbers, and three ways of getting at it |
| `activity-2-the-seating-plan/` | A working program built on a grid that means something |
| `activity-3-records-with-fields/` | A list of records, which is what real two-level data looks like |
| `activity-4-broken-structures/` | Three faults across three small programs |

Activity 3 is the one that matters. A grid of numbers is worth twenty minutes;
a list of dictionaries is what you will be reading for the rest of your career.

### Session 2: when things go wrong

| Folder | Focus |
|---|---|
| `activity-5-errors-you-have-already-met/` | Five errors you have hit this fortnight, gathered in one place |
| `activity-6-deciding-what-to-catch/` | A reader that copes with a bad file, and whether it should |
| `activity-7-the-error-that-was-hidden/` | Three faults, all of them caused by catching something |

Activity 7 is the one to reach if you can. It is the whole module's argument in
one file: code that runs, reports a number, and is wrong.

### Stretch

| Folder | Focus |
|---|---|
| `stretch-1-following-the-chain/` | A second row that holds directions rather than data |
| `stretch-2-raising-your-own/` | Deciding that a program should stop |

## How to work through these

Work in pairs. One drives, the other reads and questions, then swap at each new
activity.

You are **not** expected to finish everything. Activity 3 in the morning and
activity 7 in the afternoon are the two to aim for.

## Running a file

Change into the activity's folder first, since some activities have their own
data file:

```
cd activity-2-the-seating-plan
python seating_plan.py
```

If `python` is not recognised, use `python3` instead.
